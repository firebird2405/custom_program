# 쁘띠캘린더 (PetitCalendar) — 캘린더 / 포스트잇 월 안내

`D:\custom_program` 폴더의 캘린더와 포스트잇 월은 브라우저 없이 **독립 창(앱 창)** 으로 열리는
로컬 HTML 앱입니다. Microsoft Edge의 앱 모드를 이용하므로 별도 설치가 필요 없습니다.

> 이 문서는 **로컬판(Edge 앱 모드)** 사용 안내입니다. 두 앱을 하나로 묶은 **스토어판(Electron,
> 브랜드명 "쁘띠캘린더/PetitCalendar")** 은 MS 스토어 출시를 준비 중이며, 아래
> "[스토어판 안내](#스토어판-쁘띠캘린더--electron)" 절과 `protocol/STORE-GUIDE.md` 를 참고하세요.

## 실행 방법

1. **가장 간단한 방법**: `launch_calendar.vbs` 또는 `launch_postit.vbs` 를 더블클릭합니다.
   둘 다 열려면 `launch_all.vbs` 를 더블클릭하세요. (검은 콘솔 창은 뜨지 않습니다)
2. **바탕화면 바로가기 만들기**: `make_shortcuts.ps1` 을 우클릭 → "PowerShell에서 실행".
   바탕화면에 "캘린더", "포스트잇 월" 아이콘이 생깁니다. 다시 실행하면 기존 바로가기를 덮어씁니다.
3. Edge가 설치되어 있지 않으면 한국어 오류 메시지가 표시됩니다.

## 주요 기능

### 포스트잇 월 (postit.html)

- **기본**: "+ 새 포스트잇"으로 생성, 내용 입력, 색상 선택(4색 이상), 마우스로 자유롭게 드래그 배치. 모든 변경은 즉시 저장됩니다.
- **우클릭 메뉴**: 노트를 우클릭하면 색상·스킨·복제·맨 앞으로·삭제 등, 보드 빈 곳을 우클릭하면 "여기에 새 포스트잇"·정리 등의 메뉴가 나옵니다.
- **체크리스트**: 노트에 `- [ ] 할 일` 형식으로 줄을 쓰면 체크박스로 표시되고, 체크하면 취소선이 그어집니다.
- **크기 조절**: 노트 모서리의 핸들을 드래그해 크기를 바꿀 수 있습니다 (최소 120, 최대 480px).
- **검색**: 검색창에 키워드를 입력하면 일치하는 노트만 밝게, 나머지는 흐리게 표시됩니다.
- **한 번에 정리**: 정리 버튼을 누르면 흩어진 노트가 겹침 없이 격자로 정돈됩니다 (이후에도 자유 배치 가능).
- **보드 여러 개**: 상단 탭에서 보드를 추가/전환해 업무·개인 등으로 나눠 쓸 수 있습니다.
- **보드 이름·탭 메뉴**: 보드 탭을 더블클릭하면 이름을 바로 바꿀 수 있고(최대 20자, 빈 값이면 기본 이름),
  탭을 우클릭하면 열기/이름 바꾸기/삭제 미니 메뉴가 나옵니다. 보드 삭제를 실행 취소하면 이름까지 복원됩니다.
- **사진 포스트잇**: 노트 메뉴에서 로컬 이미지를 첨부하면 자동으로 축소되어 저장됩니다.
- **노트 스킨**: 기본/줄노트/모눈 스타일을 노트별로 선택할 수 있습니다.
- **삭제 실행 취소**: 노트를 삭제하면 잠시 "실행 취소" 버튼이 떠서 되돌릴 수 있습니다.
- **백업**: 내보내기/가져오기 버튼으로 JSON 파일 백업·복원이 됩니다.
- **예전 메모 가져오기**: 구버전 memo.html 에 쓰던 메모를 포스트잇으로 변환해 가져올 수 있습니다 (원본 메모는 파괴되지 않습니다).
- **캘린더 연동**: 노트 메뉴에서 "날짜 지정"으로 날짜를 달면 캘린더의 그 날짜에 📌 일정이 자동 생성됩니다. 날짜를 바꾸거나 해제하면 연동 일정도 따라 이동/삭제됩니다.
- **설정 패널 (⚙️)**: 노트 글자 크기·폰트(손글씨/고딕), 새 노트 기본 색·크기·기울임, 정리 방식,
  애니메이션 강도(켬/줄임/끔), 음소거·볼륨, 데이터 관리(내보내기/가져오기 · 저장 용량 게이지 · 손상 백업 정리)를 한곳에서 조절합니다.
- **정리 방식 선택**: ✨ 정리 버튼이 설정의 [배치]에서 고른 5가지 방식(기본 / 3×3 격자 / 2×2 격자 / 동적 마소너리 / 시간순) 중 하나로 동작합니다.
- **보드 삭제**: 보드 탭·우클릭 메뉴에서 보드를 지울 수 있고, 잠시 뜨는 "실행 취소"로 노트까지 통째로 되살릴 수 있습니다
  (기본 보드와 마지막 남은 보드는 지워지지 않습니다).
- **꾸미기 (🎨)**: 보드 배경(기본 코르크 / 나무 / 리넨 / 칠판 / 내 사진 — 채우기·타일 선택), 이모지 스티커 3세트(계절·자연/기분/사무),
  폴라로이드 사진 스티커, 테이프 색·무늬, 보드 프레임 색을 바꿀 수 있습니다. 배경은 보드마다 따로 저장되고,
  스티커는 항상 포스트잇 뒤에 깔리며, 스티커·배경을 지워도 "실행 취소"로 되돌릴 수 있습니다.

### 캘린더 (calendar.html)

- **기본**: 월간 그리드, 일정 추가/수정/삭제, 2026–27 대한민국 공휴일(대체공휴일 포함) 표시.
- **반복 일정**: 매주 등 반복 규칙으로 일정을 만들 수 있고, 특정 회차만 골라 삭제할 수도 있습니다.
- **D-day**: 일정을 기념일로 지정하면 D-3 같은 배지가 표시됩니다.
- **카테고리 색**: 일정마다 카테고리 색(3색 이상)을 달아 달력의 점 색으로 구분됩니다.
- **알림**: 앱이 떠 있는 동안 일정 시각이 되면 화면 안 알림(토스트)과 소리로 알려줍니다.
- **음력 표기**: 각 날짜 칸에 음력 날짜가 함께 표시됩니다.
- **주간 뷰**: 월간 ↔ 주간 보기를 전환할 수 있고, 마지막 보기 상태가 기억됩니다.
- **우클릭 메뉴**: 날짜 칸 우클릭 → "이 날짜에 일정 추가", 일정 우클릭 → 수정·삭제·복제.
- **삭제 실행 취소 / 백업**: 포스트잇과 동일하게 실행 취소 토스트와 내보내기/가져오기를 지원합니다.
- **설정 패널 (⚙️)**: 글자 크기, 주 시작 요일(일/월), 음력 표시·D-day 배지 켬/끔, 알림 켬/끔과 알림 시점(정각/5분 전/15분 전),
  애니메이션 강도, 음소거·볼륨, 데이터 관리(내보내기/가져오기 · 저장 용량 게이지 · 손상 백업 정리)를 조절합니다.
- **배경 꾸미기**: 설정의 [꾸미기]에서 종이/리넨 프리셋 또는 내 이미지를 달력 카드 뒤에 은은하게 깔고, 강도 슬라이더로 진하기를 조절할 수 있습니다.

### 두 앱 공통

- **테마 프리셋**: 앱 안에서 코르크+파스텔(기본) / 다크+비비드 / 미니멀 화이트 3종 테마를 전환할 수 있고, 앱별로 기억됩니다.
- **볼륨**: 볼륨 슬라이더(0~100)로 효과음 크기를 조절하거나 끌 수 있습니다.
- **안전 장치**: 같은 앱을 두 창으로 열어 각각 입력해도 양쪽 모두 보존되고, 저장 데이터가 손상돼도 크래시 없이 열리며 손상 원본은 백업 키로 남습니다.
- **실행 취소 원칙**: 노트·일정·보드·스티커·배경 등 지우는 동작은 확인 창 없이 바로 실행되고,
  잠시 뜨는 토스트의 "실행 취소" 버튼으로 되돌릴 수 있습니다.
- **삭제 전 확인(선택)**: ⚙️ 설정의 [안전]에서 "삭제 전 확인"을 켜면 노트·보드·일정·스티커 등을
  지우기 전에 앱 안 확인 창("정말 삭제할까요?")이 한 번 더 물어봅니다. 기본은 꺼짐이며,
  켜도 실행 취소 토스트는 그대로 제공됩니다.
- **창 크기·위치 기억**: 창을 옮기거나 크기를 바꾸면 앱이 기억해 두었다가 다음 실행 때
  같은 자리·크기로 복원합니다 (첫 실행에만 기본 크기로 열립니다).

## 색상(테마) 바꾸기

- **간단한 방법**: 각 앱 안의 **테마 프리셋** 버튼으로 코르크+파스텔 / 다크+비비드 / 미니멀 화이트를 바로 전환하세요 (재실행해도 유지됩니다).
- **세부 조정(고급)**: `calendar.html` 과 `postit.html` 을 메모장 등 텍스트 편집기로 열면
  파일 상단 `<style>` 안에 `:root { ... }` 블록이 있습니다.
  여기의 CSS 변수(`--` 로 시작하는 값)가 앱 전체 색상을 결정하므로,
  원하는 색상 코드(예: `#4a90d9`)로 바꾸고 저장한 뒤 앱을 다시 열면 적용됩니다.

## 데이터는 어디에 저장되나요?

- 일정과 포스트잇은 각 앱 전용 Edge 프로필 폴더
  `D:\custom_program\.edge\calendar`, `D:\custom_program\.edge\postit` 안의
  **localStorage** 에 저장됩니다. 인터넷에 올라가지 않고 이 PC에만 있습니다.
- 주요 저장 키: 일정은 `cal-events`, 포스트잇은 `postit-notes`(추가 보드는 `postit-notes-…`),
  테마·볼륨 등 설정은 `cal-…`/`postit-…` 접두 키에 각각 저장됩니다.
  설정 패널 값은 `cal-settings`/`postit-settings`, 꾸미기(스티커 배치·배경 설정)는
  `postit-decor-layout`/`cal-decor` 키에 저장됩니다.
- 꾸미기의 **큰 이미지**(보드 배경 사진·사진 스티커·캘린더 배경 이미지)는 localStorage 용량(약 5MB)을
  차지하지 않도록 같은 프로필 안의 **IndexedDB**(`postit-decor` / `cal-decor`)에 따로 저장됩니다.
  내보내기에서 "이미지 포함"을 켜면 이 이미지들도 백업 파일에 함께 담깁니다.
- 앱 안의 **내보내기(Export) / 가져오기(Import)** 버튼으로 데이터를 파일로 백업하거나
  다른 PC로 옮길 수 있습니다. 중요한 데이터는 주기적으로 내보내기를 해 두세요.
- 이 폴더 전체는 **git 저장소**로도 관리됩니다 (원격: `github.com/firebird2405/custom_program`).
  `.edge` 프로필(라이브 데이터)은 커밋되지 않지만, `backups\` 스냅샷 JSON은 저장소에 포함됩니다.

> **주의: `.edge` 폴더를 삭제하지 마세요!**
> 이 폴더를 지우면 모든 일정/포스트잇 데이터가 사라집니다.
> 데이터를 초기화하고 싶은 경우에만, 반드시 먼저 **내보내기**로 백업한 뒤 삭제하세요.

## 자동 시작 (로그인하면 자동으로 열기)

- **켜기**: `install_startup.ps1` 을 우클릭 → "PowerShell에서 실행".
  시작프로그램 폴더에 "캘린더"/"포스트잇 월" 바로가기가 등록되어
  다음 로그인부터 두 앱이 자동으로 열립니다.
- **끄기**: `uninstall_startup.ps1` 을 같은 방법으로 실행하면 등록이 해제됩니다.
  (앱 데이터와 바탕화면 바로가기는 그대로 유지됩니다)
- **참고**: 자동 채점(`npm test`)의 A38 항목은 등록 → 해제 순으로 실제 실행해 검사하므로,
  채점을 돌린 뒤에는 자동 시작이 꺼진 상태가 됩니다. 계속 쓰려면 `install_startup.ps1` 을
  한 번 더 실행하세요.

## 파일 백업 (backup_snapshot.ps1)

- `backup_snapshot.ps1` 을 실행하면 두 앱의 데이터(localStorage 전체)가
  `D:\custom_program\backups\` 아래에
  `calendar-YYYYMMDD-HHMMSS.json` / `postit-YYYYMMDD-HHMMSS.json` 으로 저장됩니다.
- 실행할 때마다 새 타임스탬프 파일이 **추가**되며, 기존 백업은 절대 덮어쓰지 않습니다.
- 앱 창이 열려 있으면 프로필이 잠겨 실패할 수 있으니 **앱을 닫고** 실행하세요.
- 스냅샷에는 **localStorage 데이터만** 담깁니다. 꾸미기 이미지(IndexedDB)까지 백업하려면
  앱 안의 **내보내기**에서 "이미지 포함"을 켜서 저장하세요.

## 항상 위 고정 (pin_top.ps1 / unpin.ps1)

- 앱 창을 띄운 상태에서 `pin_top.ps1` 을 실행하면 캘린더·포스트잇 월 창이
  다른 창 위에 항상 표시됩니다. `unpin.ps1` 로 해제합니다.
- 두 스크립트는 이 앱의 창(명령줄에 `D:\custom_program` + `--app` 이 있는 Edge 창)만
  건드리고, 다른 프로그램 창은 변경하지 않습니다.

## 스토어판 (쁘띠캘린더 · Electron)

- 이 폴더의 Edge 앱 모드판과 별개로, MS 스토어 출시용 **스토어판**이 `electron\` 아래 준비되어 있습니다.
  브랜드명은 한글 **쁘띠캘린더** / 영문 **PetitCalendar** 입니다.
- 스토어판은 두 앱이 **한 창의 탭**(캘린더 / 포스트잇 월)으로 열립니다. 창은 **언제나 하나**이고,
  탭을 오가도 입력 상태가 유지됩니다.
  (탭을 별도 창으로 분리하는 기능은 **폐지됐습니다** — 발주 #16, 채점표 rev.8 A42.)
- 기존 Edge판 데이터는 스토어판 첫 실행 때 자동으로 이전됩니다 (원본은 건드리지 않습니다).
- 이번 판은 **완전 무료 단독**입니다 — 광고 없음 · 로그인 없음 · 앱 안 결제 유도 없음.
  **보드 개수 제한도, 예약 자동 백업 잠금도 없습니다** (채점표 rev.9 · 감사 권고 #24·#25).
  Pro(신규 스티커 팩 · 프리미엄 테마)는 실제 구매 동선과 상품 신규성을 함께 갖춘 뒤에만
  다시 검토합니다 — 살 수 없는 잠금은 넣지 않습니다.
- 스토어 리스팅은 **한국어 단독**으로 냅니다. 앱 UI 가 한국어 전용이라 영문 리스팅은
  UI 영문화 이후로 **보류**했습니다 (영문 자산 `store-assets/store-description.en.md`·`store-assets/en/`·
  `PRIVACY.en.md` 는 그때 쓰려고 남겨 둡니다 — 발주 #27).
- 출시 절차는 `protocol/STORE-GUIDE.md`, 사업 검토는 `protocol/MARKET.md`,
  스토어 자산의 제출용/보조용 구분은 `store-assets/README.md`,

## 지인 배포판 만들기 (make_dist.ps1)

스토어 심사 전에 지인에게 먼저 써 보게 할 때 쓰는 **포터블 ZIP**을 한 명령으로 만듭니다.
설치 없이 압축만 풀면 실행되는 형태이고, 개인 데이터가 섞여 나가지 않는지 스크립트가 직접 검사합니다.

**1) 먼저 Electron 패키지를 빌드합니다** (이미 빌드해 뒀으면 건너뜁니다)

```
cd D:\custom_program\electron
npm ci
npm run dist
```

→ `electron\dist\win-unpacked\` 생성 (이 폴더가 배포판의 원본입니다)

**2) 배포판 ZIP을 만듭니다**

```
powershell -ExecutionPolicy Bypass -File D:\custom_program\make_dist.ps1
```

문의처를 미리 채워 넣으려면 `-Contact` 를 붙입니다.

```
powershell -ExecutionPolicy Bypass -File D:\custom_program\make_dist.ps1 -Contact "uto2405@gmail.com"
```

**산출물**

- `D:\custom_program\dist_out\PetitCalendar-<버전>-portable.zip` (예: `PetitCalendar-0.9.0-portable.zip`, 약 118MB)
- ZIP 최상위는 `PetitCalendar-<버전>\` 폴더 하나 — 풀어도 파일이 흩어지지 않습니다.
- 그 안에 **`읽어주세요.txt`** 가 함께 들어갑니다 (실행법 · 저장 위치 · 삭제 방법 · 문의처 · 무료/광고 없음 안내).
- 실행 후 콘솔에 ZIP **크기와 SHA256**이 출력됩니다 — 파일을 보낼 때 이 해시를 같이 알려주면 받는 쪽이 검증할 수 있습니다.

**스크립트가 자동으로 막아 주는 것**

- `electron\dist\win-unpacked` 가 없으면 위 빌드 명령을 안내하고 **중단**합니다 (빈 ZIP 방지).
- **개인 데이터 블랙리스트 검사** — `backups` · `.edge` · `protocol` · `.git` · `Local Storage` ·
  `IndexedDB` · `Session Storage` · `*.log` · `*.ldb` · `*.sqlite` · `window-state.json` ·
  `shell-settings.json` 중 하나라도 있으면 **중단**합니다. 검사는 패키지 폴더와 완성된 ZIP 양쪽에서 합니다.
  (채점기 A46이 쓰는 것과 같은 기준입니다.)
- 저장소의 `calendar.html`/`postit.html` 이 패키지 안의 것보다 새로우면 **"이전 빌드가 나간다"고 경고**합니다.
  이 경고가 보이면 `npm run dist` 로 다시 빌드한 뒤 배포판을 만드세요.

**주의**

- `dist_out\` 은 `.gitignore` 에 등록되어 있습니다 (100MB대 산출물 — 커밋하지 않습니다).
- 코드 서명이 아직 없어서 받는 사람 PC에서 **"Windows의 PC 보호"** 창이 뜹니다.
  `읽어주세요.txt` 에 [추가 정보] → [실행] 안내가 들어 있으니, 보낼 때 한 번 더 짚어 주세요.
- 보내기 전에 **다른 계정/다른 PC에서 압축을 풀고 실행**되는지 한 번 확인하는 것을 권합니다.
- 확산 문안·배포 채널은 `protocol/LAUNCH-KIT.md` 를 참고하세요.
