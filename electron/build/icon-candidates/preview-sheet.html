쁘띠캘린더 아이콘 후보 3안

시사용 비교 시트 — 각 안을 512 / 150 / 44 px로 렌더 (배경 체커 = 투명 영역). 적용은 시사 후.

A

코르크 + 포스트잇 실사 감성

코르크 보드 질감(프로시저럴 노이즈) 위에 압정으로 고정된 노란 포스트잇, 말린 모서리와 마커 하트 낙서.

B

파스텔 플랫 미니멀

민트 바탕에 바인더 링 캘린더 격자(한 칸 강조) + 우하단에 접힌 포스트잇 모서리. 플랫 오프셋 섀도.

C

손글씨 캐릭터풍 P 모노그램

크림 종이에 크레용 획의 P(쁘띠) 모노그램 — 볼 안에 웃는 얼굴, 물방울 마스킹 테이프와 하트·반짝임 낙서.
