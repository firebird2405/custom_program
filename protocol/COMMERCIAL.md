# 상업화 검토 — 캘린더 + 포스트잇 월 (2026-08-13)

사용자 제안(반디집 모델: 무료 배포 + 1회 구매 유료 기능 + 기본판 배너 광고)에 대한 검토 결론과 실행 로드맵.

## 결론 요약

- **방향성 유효**: 무료 배포 + 1회 구매 업그레이드는 적합. 단 **배너 광고는 제외 권고**.
- **포지셔닝**: "메모/일정 앱"(경쟁: Windows 스티커 메모·Google Keep — 전부 무료)이 아니라 **"감성 데스크톱 문구(다꾸 감성)"**로. 차별점 = 물성(코르크·손글씨·사운드)·꾸미기·오프라인 완결(데이터 로컬 소유).
- **기대치**: 잘 되면 용돈~부업 규모. 대박 모델 아님을 전제로 리스크 최소 순서 진행.

## 광고 제외 근거 (검토 완료)

1. 기술: 애드센스류는 로컬 앱(file://) 승인 불가. 광고 = 외부 요청 = 오프라인 완결 원칙(A1) 붕괴.
2. 수익성: 데스크톱 위젯 배너는 수천 사용자여도 월 수만 원 수준.
3. 브랜드: 감성 제품에 배너는 정체성 훼손 — 유료 전환 유인마저 깎음.
4. 반디집 모델 성립 배경(필수 유틸 대규모 설치 기반 + 기업 라이선스 수익)이 이 제품군엔 부재.

## 유통 (2026-08-19 사용자 문제 제기로 재정리 — "MS 스토어 거의 안 팔리지 않나?")

- **결론: 스토어 = 판매대가 아니라 인프라.** 스토어 유기 유입은 0에 수렴한다고 전제한다(사용자 직감 타당). 스토어의 실효 가치는 코드 서명(SmartScreen 해제)·Pro 결제·자동 업데이트·설치 신뢰 4가지.
- **투트랙 전략**: ① 발견 = 스토어 밖 — 다꾸/문구 커뮤니티(인스타·X·네이버 카페)·클리앙/뽐뿌·유튜브 쇼츠 + 무료판 직배포(ZIP/NSIS) 병행, ② 결제·배송 = MS 스토어.
- **플랜 B (스토어 사망 판정 시)**: Pro 라이선스가 서명 파일 방식이라 스토어 독립 판매 가능 — Gumroad류 결제→라이선스 자동 발급(gen-license.js 기반). 이미 설계에 내장됨.
- 1차 게이트(3개월 1,000 다운로드)는 커뮤니티 확산으로 달성하는 숫자 — 출시 직후 "확산 트랙" 발주(채널별 포스팅 계획) 필요.
