# 쁘띠캘린더 (PetitCalendar) — 스토어 설명문

## 한 줄 소개

내 책상 위 코르크 보드를 그대로 옮긴, 오프라인 감성 캘린더 + 포스트잇 월이에요.

## 설명

쁘띠캘린더는 캘린더와 포스트잇 월, 두 개의 아담한 창으로 하루를 정리하는 데스크톱 다이어리예요.
손글씨 폰트와 코르크 보드 위에 알록달록한 포스트잇을 자유롭게 붙이고, 끌어서 옮기고,
마스킹 테이프와 이모지 스티커로 나만의 보드를 꾸며 보세요. 다이어리 꾸미기(다꾸)의 아기자기한
손맛을 화면 위에 그대로 담았어요.

캘린더에는 2026–2027 대한민국 공휴일이 미리 들어 있고, 일정마다 색 카테고리와 D-day 배지를
붙일 수 있어요. 엄마 생신까지 며칠 남았는지, 여행까지 얼마나 남았는지 한눈에 보여요.

**인터넷이 없어도 완전하게 동작해요.** 로그인도, 회원가입도, 서버도 없어요.
일정과 메모는 오직 내 PC에만 저장되고, 그 누구에게도 전송되지 않아요.
내 기록의 주인은 나 — 데이터를 온전히 내가 소유하는 앱이에요.

실수로 창을 두 개 열어도 양쪽 입력이 모두 보존되고, 저장 데이터가 손상되어도 원본을 안전하게
백업해 두는 든든한 구조까지. 작지만 야무진 쁘띠캘린더와 함께 오늘 하루를 예쁘게 붙여 두세요.

## 주요 기능

- 포스트잇 월: 자유 배치 · 5색 팔레트 · 체크리스트 · 사진 메모 · 보드 여러 개
- 캘린더: 월간/주간 보기 · 공휴일 · 음력 · 반복 일정 · D-day 배지 · 일정 알림
- 꾸미기: 배경 프리셋 · 이모지/사진 스티커 · 마스킹 테이프 · 액자 프레임
- 프리미엄: 스티커 2팩(여행·간식, 동물 친구들) + 프리미엄 테마 2종(딥씨·라벤더) + 보드 무제한
- 오프라인 완결: 외부 요청 0건 — 모든 데이터는 내 PC에만, 로그인 없음
